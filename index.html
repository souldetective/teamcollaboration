How much software data can be assembled from official public sources?

This single-file prototype is intentionally static HTML. The goal is not a finished app; it is to show the publicly verifiable data fields that can be collected for project-management tools without reviews, competitor articles, fabricated claims, or copyrighted copy.

What data is easy vs hard?

EasyPricing, free plans, core features, integrations, apps, API docs.
MediumSecurity controls, compliance scope, exact platform support, changelog detail.
HardEmployee counts, customers, funding, granular usage limits, exact data residency scope.
OmittedReviews, ratings, subjective scores, competitor claims, unverified fields.

Internal metadata model represented by this HTML

Each visible field can map to: value, source URL, last verified date, confidence score, and extraction method. In a later database-backed app, this HTML could become generated output from records rather than hand-maintained markup.
